# 复合肥配方推荐工具

这个工具基于附件 `.xls` 的结构做成静态网页，直接打开 `index.html` 即可使用。

## 原表结构

- 工作表分为 `转鼓` 和 `挤压` 两套工艺。
- 第 4 行是原料单价，第 5 行是原料名称，第 6 行是理论配方 kg/t。
- 第 7 行是折水、损耗后的实际量，核心逻辑为：`理论投料 * (1 - (原料含水量 - 成品水分)) * 损耗系数`。
- 第 9 行是配方百分比。
- 第 10-22 行是 N、P、K、硝氮、有机质、微量元素、水分、氯离子、PH、水溶磷或水不溶物。
- 标准成本按理论 1000 kg 配方计算；实际成本按折后产出量折算，再加加工费用。原表中转鼓加工费用按 280 元/t，挤压按 180 元/t 作为初始值。

## 推荐算法

工具以 1000 kg/t 理论配方为基础，把配合式解析成 N-P-K。算法不再把单一养分精确卡死，而是按 GB/T 15063 的单养分偏差口径建立允许区间：默认允许单一养分安全下调 1.0%，上浮按 1.5% 控制，同时要求总养分不低于页面填写的下限。这样成本优化会优先把较贵的单一养分往安全范围内压低，再用成本更合适的养分补足总养分。

推荐结果的投料配比按整数百分比输出，例如 55%、30%，对应 550 kg/t、300 kg/t，不输出小数配比。

氯离子等级按 GB/T 15063 做内置筛选：硫基低于 3%，低氯不高于 15%，中氯不高于 30%，高氯高于 30%。水溶磷比例为页面手动填写的下限；留空时不筛选。排序时会优先选择贴近下限的方案，而不是继续追求更高的水溶磷。

## 原料维护

原料、价格、损耗系数、上限 kg/t 和各项指标都可以在页面下方维护。修改会保存在当前浏览器的本地存储中；需要迁移到其他电脑时，可以用“导出数据”和“导入数据”。

## 复核点

附件中的样例名称如 `18-7-10`、`30-10-5` 与表内当前计算出的 N/P/K 结果不完全一致。本工具以表格中的真实指标行和公式逻辑为准。正式用于生产前，建议用历史配方做一次人工复核，尤其是各原料的水溶磷比例数据。
